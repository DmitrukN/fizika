# AGENTS.md — «Физика»

Мобильные мемо-карточки по физике. Один раздел, один ученик, прогресс локальный. Разделы будут добавляться.

## Стек

- Vite + React + TypeScript.
- KaTeX для формул, без картинок.
- Обычный CSS с токенами; UI-библиотек, Tailwind и CSS-in-JS нет.
- Vitest для юнит-тестов, Playwright для сквозного сценария.

## Команды

```powershell
npm run dev
npm run typecheck
npm test
npm run build
npx playwright test
```

## Карта

- `src/content/` — карточки и разделы, типизированные данные.
- `src/domain/` — планировщик и типы; чистые функции, без React и DOM.
- `src/storage/` — чтение и запись `localStorage`, версия схемы.
- `src/screens/` — старт, сессия, прогресс.
- `src/components/` — карточка, кнопки, полоски.
- `docs/specs/`, `docs/adr/` — спека и решения.
- `.scratch/flashcards/issues/` — тикеты.

## Правила

- Спека `docs/specs/0001-molecular-physics.md` — источник истины по поведению.
- Правила интервалов живут только в `src/domain/scheduler.ts`. Компоненты их не повторяют.
- Экраны не обращаются к `localStorage` напрямую: только через `src/storage/`.
- Планировщик не знает ни о React, ни о датах в виде строк UI. На вход — локальный день `YYYY-MM-DD`.
- Даты считаются по локальному календарному дню. `toISOString()` для дат не использовать: он уводит на UTC.
- Данные карточек не парсятся из LaTeX при сборке. Источник правды — `src/content/`.
- Битые данные в `localStorage` — явная ошибка с кнопкой сброса, не молчаливый старт с нуля.
- Новые зависимости — только если без них решение заметно дороже. KISS и YAGNI важнее «на будущее».
- Один шов для юнит-тестов — планировщик. Тесты проверяют внешнее поведение, не внутренности компонентов.

## Приёмка

1. `npm run typecheck` и `npm test` зелёные.
2. `npm run build` собирается.
3. `npx playwright test` проходит.
4. На 402 × 874 нет вертикальной прокрутки; на меньших экранах ничего не обрезается.
5. Кнопки не меньше 44 px, фокус видимый.
