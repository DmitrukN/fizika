# 01: Каркас и карточки

**What to build:** Работающее приложение, в котором можно выбрать раздел и листать 34 карточки: название → нажатие → формула и пояснение. Прогресс пока в памяти, без сохранения.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] `npm run dev` открывает стартовый экран со списком разделов и числом карточек в каждом
- [ ] «Все разделы» и любой раздел открывают сессию
- [ ] Карточки идут в случайном порядке
- [ ] Нажатие на карточку раскрывает формулу (KaTeX) и пояснение
- [ ] Кнопки «Забыл» и «Знаю» переводят к следующей карточке, счётчик «N из 34» растёт
- [ ] «Закончить» возвращает на старт
- [ ] На 402 × 874 нет вертикальной прокрутки
- [ ] `npm run typecheck`, `npm test`, `npm run build` зелёные
