# 02: Планировщик и сессия

**What to build:** Настоящая сессия: ответы сохраняются, «Знаю» откладывает карточку по лестнице интервалов, «Забыл» возвращает ее через три карточки, просрочка ждет следующего открытия. После «Закончить» — итог сессии.

**Blocked by:** 01.

**Status:** ready-for-agent

- [ ] «Знаю» на новой карточке ставит срок через 5 дней, дальше 7 и не больше
- [ ] «Забыл» ставит интервал 1 и срок на завтра, карточка возвращается после трех других в этой же сессии
- [ ] Ответ записывается в `localStorage` сразу после нажатия
- [ ] После перезагрузки страницы интервалы и сроки на месте
- [ ] В очередь попадают только созревшие карточки выбранного раздела
- [ ] Просроченная карточка не исчезает и не сдвигается
- [ ] Итог сессии показывает число ответов, «Знаю», «Забыл» и время
- [ ] Тесты планировщика покрывают все переходы и просрочку
- [ ] Битый JSON дает экран ошибки, а не старт с нуля
