# Спека 0001: «Физика» — мемо-карточки по молекулярной физике

## Problem Statement

Ученику нужно держать в памяти 34 формулы молекулярной физики. Сейчас он листает PDF-шпаргалку: формулы узнаются в лицо, но по названию не воспроизводятся, а через неделю забываются. Ни ученик, ни преподаватель не видят, что именно выветрилось, а что закрепилось. Шпаргалка не отвечает на вопрос «что повторить сегодня».

## Solution

Мобильное веб-приложение по ссылке, без установки и регистрации. Ученик выбирает раздел или все разделы, получает карточки в случайном порядке. На карточке — название формулы; нажатие открывает формулу и короткое пояснение. Две кнопки: «Знаю» откладывает карточку на 5–7 дней, «Забыл» возвращает её в этой же сессии. Прогресс хранится в браузере ученика и показывается на одном экране: что закреплено, что в работе, занимался ли он последние две недели.

## User Stories

## Implementation Decisions

### Форма приложения

- Одностраничное приложение: Vite, React, TypeScript. Без роутера — четыре экрана переключаются состоянием приложения.
- Целевой viewport — 402 × 874 CSS px, портрет. Safe area учитывается через `env(safe-area-inset-*)`. На меньших экранах допускается вертикальная прокрутка; на 402 × 874 прокрутки нет.
- Сеть обязательна; service worker и офлайн-режим не делаются.
- Формулы рендерятся KaTeX из LaTeX-строк. Картинок и скриншотов формул нет.

### Содержимое

- Колода «Молекулярная физика»: 34 карточки, 7 разделов.
- Источник — `physics/cheatsheets/10-molekulyarnaya.tex`. Три карточки изопроцессов (Бойля—Мариотта, Гей-Люссака, Шарля) взяты из блока определений, потому что отдельных строк формул там нет.
- Одна карточка = одна формула. Смысл и название карточки пишутся отдельно, чтобы по названию можно было вспомнить формулу.
- Определения, алгоритм решения задач и графики изопроцессов в колоду не входят.
- Карточки — типизированные данные в коде: `id`, `section`, `title`, `formula`, `note`. Никакого парсинга LaTeX при сборке.

### Планировщик

- У карточки одно число `interval` из набора `0, 1, 3, 5, 7` (дни) и дата `due`.
- «Знаю»: `0 → 5`, `1 → 3`, `3 → 5`, `5 → 7`, `7 → 7`. `due = сегодня + interval`.
- «Забыл»: `interval = 1`, `due = завтра`, карточка возвращается в текущую сессию после трёх других карточек.
- Просроченная карточка (`due <= сегодня`) остаётся в очереди, пока по ней не ответят. Пропущенный день ничего не сдвигает.
- Новая карточка (`interval = 0`) считается созревшей и попадает в очередь.
- Даты сравниваются по локальному календарному дню в формате `YYYY-MM-DD`, без UTC-сдвигов.

### Сессия

- Стартовый экран: 7 разделов с числом карточек, кнопка «Все разделы», при выбранном ранее разделе — кнопка «Продолжить», переход к прогрессу.
- Очередь сессии — созревшие карточки выбранного раздела в случайном порядке (Fisher—Yates).
- «Забыл» переставляет карточку на позицию через 3 карточки от текущей; если очередь короче — в конец.
- Ответ записывается в хранилище немедленно, до показа следующей карточки.
- «Закончить» доступна всегда и показывает итог сессии. Неотвеченные карточки остаются созревшими.
- Пустая очередь: сообщение «На сегодня всё» и две кнопки — «Повторить все» (берёт все карточки раздела, не меняя интервалы) и «Назад».
- Последний выбранный раздел запоминается и подставляется на старте.

### Прогресс

- «Закреплено» = интервал 7, «в работе» = 1–5, «не начато» = 0.
- Экран прогресса: сводка по колоде, 7 строк по разделам с полосками, полоса последних 14 дней, точность за всё время и за последнюю сессию.
- Точность = «Знаю» / все ответы. Считается по журналу ответов.
- Журнал ответов хранится локально; приложение не заявляет, что его нельзя подделать.

### Хранение

- Одно ключевое слово в `localStorage`: `fizika.v1`. JSON с полем `version`.
- Сохраняются: интервалы и сроки карточек, счётчики ответов, журнал сессий, дни занятий, последний раздел.
- Чтение при старте: если JSON битый или версия неизвестна — экран ошибки с причиной и кнопкой «Сбросить прогресс». Молча начинать с нуля запрещено.
- Схема версионируется; миграций в v1 нет.

### Интерфейс

- Направление «лабораторный журнал»: холодный светлый фон, графитовый текст, один кобальтовый акцент, тонкие линии вместо карточек с тенями, моноширинные цифры.
- Системный шрифт iOS для интерфейса, KaTeX для формул. Внешние шрифты не подключаются.
- Кнопки «Забыл» — контур, «Знаю» — заливка акцентом. Высота не меньше 48 px.
- Анимация только на открытии формулы: короткое появление, отключается при `prefers-reduced-motion`.
- Контраст текста не ниже 4.5:1, фокус видимый.

## Testing Decisions

- Тестируется внешнее поведение, не внутреннее устройство компонентов.
- Единственный шов для юнит-тестов — чистый модуль планировщика: переходы интервалов, расчёт срока, просрочка, возврат после «Забыл». Табличные тесты.
- Второй шов — модуль хранения: сериализация, чтение, обнаружение битых данных.
- Третий — проверка содержимого: 34 карточки, уникальные `id`, непустые поля, у каждой карточки существующий раздел.
- Сквозной сценарий через Playwright: выбрать раздел → открыть формулу → ответить «Забыл» → увидеть возврат → ответить «Знаю» → закончить → увидеть итог → открыть прогресс.
- Приёмка вручную: сборка, проверка на 402 × 874, отсутствие прокрутки, скриншоты ключевых экранов.
